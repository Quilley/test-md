## Working with them
- Before starting new work, look through the places above for work already in
  flight on the same thing.
- Keep each record's status true, in its owner's words. With no owner, open
  the file with a `Status:` line: draft, active, shipped, dropped, or
  superseded by <path>.
- Record a decision with the reasons the user gave or the work showed, and
  label any you supplied yourself as assumptions. A settled decision is
  superseded by a new one that says so, not rewritten.
